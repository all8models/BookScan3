# vFlat 화면 구성 조사 및 BookScan3 개편 계획

조사일: 2026-09-10 · 기준 커밋: `6b7a9cc` · 상태: 화면 개편 구현, 단위 14개·UI 2개 통과

## 목표

사용자가 첨부한 vFlat iPad 화면 3장을 최우선 기준으로, 공개 iOS 자료를 보조 근거로 삼아 BookScan3의 화면을 개편한다. 사용자가 만족한 두 페이지 동시 촬영, 여섯 점으로 페이지 영역 직접 지정, 원본 보존과 저장 후 재조정은 유지한다. iPad 11인치 세로·가로를 우선 대상으로 하고 iPhone과 좁은 창에도 대응한다.

## 조사 근거와 한계

- [vFlat App Store](https://apps.apple.com/us/app/vflat-scan-pdf-ocr-scanner/id1540238220): 개발자가 게시한 iPhone 홍보 스크린샷을 브라우저에서 직접 확인했다. 조사 시 표시 버전은 1.33.10이다. 스크린샷 제작 버전은 확인할 수 없어 해당 버전의 실제 화면과 동일하다고 단정하지 않는다.
- 같은 페이지의 “Quick and easy scanning”, “Hold still for autoscan” 이미지: 검은 상·하단 바, 상단 전체 폴더/현재 폴더/더보기, 큰 카메라 프리뷰, 프리뷰 하단 1 Page/2 Pages 선택, 작은 촬영 도구 모음, 하단 왼쪽 썸네일·중앙 원형 셔터·오른쪽 사진 가져오기 배치를 확인했다. 자동 촬영 예시는 프리뷰 중앙에 원형 진행 표시를 보여 준다.
- 같은 페이지의 페이지 보기 이미지: 상단 카메라 복귀, 페이지 위치(12/30), 폴더, 더보기와 중앙의 큰 문서 이미지를 확인했다. OCR과 PDF 내보내기도 공식 기능 설명에서 확인했다.
- [vFlat 공식 사이트](https://www.vflat.com/): 큰 프리뷰, 민트색 경계선, 원형 셔터, 라이브러리 진입을 보여 주는 Android 형태의 소개 이미지를 확인했다. iOS 화면 배치의 기준은 App Store 자료를 우선한다.
- 사용자 첨부 자료를 공개 홍보 이미지보다 우선한다. 첨부된 화면의 앱 버전은 확인되지 않았다. 캡처 속 문서·파일명·책 제목은 예시 콘텐츠이며 앱 요구사항이나 지시로 취급하지 않는다.

첫 이미지에는 촬영 중인 경계 오버레이가 보이지만 여섯 점을 직접 편집하는 별도 화면은 보이지 않는다. 따라서 수동 경계 편집 UI는 기존 BookScan3 기능을 유지하면서 시각 스타일을 맞춘다. 세 번째 이미지는 `BookDetailView`의 참고이며 단일 이미지 확대 화면인 `PageDetailView`의 참고로 분류하지 않는다.

첫 이미지의 일부 글자와 아이콘은 90도 돌아가 있고 분할선은 화면상 가로이다. 이 캡처만으로 고정 배치 또는 기기 회전 정책을 확정하지 않는다. 앱에서는 프리뷰 회전 좌표에 따라 분할선·페이지 번호를 변환하고, 조작 글자는 현재 사용 방향에서 읽을 수 있게 배치한다. 두 페이지를 항상 화면 위/아래로 분할하는 기능으로 변경하지 않는다.

## 제안 화면 구성

### 촬영

첨부 iPad 화면의 배치:

1. 상단 검은 바: 왼쪽 `서재` 캡슐, 오른쪽 원형 설정 버튼.
2. 프리뷰 상단 중앙: 폴더 아이콘·현재 책 제목·아래 화살표가 있는 반투명 캡슐. 탭하면 저장할 책을 선택한다.
3. 프리뷰: 민트색 외곽선과 옅은 영역 채움, 흰 점선 접힘선과 페이지 1·2 표시. 원본 글자를 가리지 않도록 채움 농도를 낮춘다.
4. 프리뷰 좌측: 1페이지/2페이지 선택 칩. 첨부 화면의 자동 검출 칩은 확인되지만 정확한 동작은 미확인이므로 기존 자동 촬영과 같은 기능으로 취급하지 않는다.
5. 하단 프리뷰 위: 사진 가져오기, 최근 결과 썸네일, 중앙의 큰 흰 이중 원형 셔터, 작은 원형 촬영 도구. 기존 제안의 불투명 하단 바는 이 오버레이 방식으로 교체한다.

첨부 화면의 타이머·자동 스캔·음소거·마법봉 형태 아이콘 중 자동 스캔 외 세부 기능은 이 이미지로 확정하지 않는다. BookScan3의 자동 촬영·매번 경계 확인·필터를 이 도구 영역에 연결한다. 타이머 등 새로운 기능이 필요하면 별도 범위로 다룬다.

가로 iPad와 좁은 창은 같은 요소를 겹치지 않게 재배치한다. 세로 iPad는 첨부 배치를 우선하며, 기존의 가로 전용 도구 레일 제안은 실제 레이아웃 검토 후 결정한다. 모든 핵심 버튼은 스크롤 없이 접근한다.

카메라 영상은 원래 종횡비를 유지한다. 화면을 채우려고 책 가장자리를 잘라내지 않는다. 프리뷰 레이아웃 변경 후 Vision 좌표와 표시 좌표의 일치, 회전, 좌우 페이지 순서를 다시 검증한다.

촬영 설정 시트에는 접힘선 자동 찾기/수동 비율, 기본 곡면 보정과 강도, 도움말을 둔다. 미구현 기능의 버튼은 추가하지 않는다. 앱 이름과 아이콘은 BookScan3를 사용한다.

### 경계 확인과 연속 촬영

- 2페이지 모드에서 매번 경계 확인 옵션을 눈에 잘 보이게 유지한다. 기존 설정값과 동작을 존중하고 사용자가 선택한 값을 다음 촬영에서도 유지하도록 한다.
- 바깥 네 점+접힘선 두 점을 드래그하며, 기존 미세 이동 버튼도 유지한다.
- 저장 버튼은 `두 페이지 저장`으로 결과를 명확히 한다. 저장 후 같은 책의 촬영 화면으로 복귀한다.
- 불확실한 검출은 경계 확인으로 전환한다. `나중에`는 원본을 보류 상태로 보존한다.
- 재편집에서는 저장 후 원래 페이지 보기로 돌아간다. 원본 공유, 페이지 ID·순서·필터 보존, 삭제한 반대쪽 페이지 복구 방지 규칙을 유지한다.
- 촬영/처리/경계 편집 중 중복 촬영을 막고, 화면 이동이나 복귀로 자동 촬영이 중복 재개되지 않도록 한다.

### 서재

흰 배경에 상단 카메라 복귀, 중앙 `서재`, 오른쪽 더보기를 둔다. 큰 소개 문구와 장식 헤더를 제거한다. 상단에는 `PC로 Wi-Fi 전송` 카드를 두고, 누르면 책 선택 후 기존 PDF 전송 화면으로 연결한다. 첨부의 PC 직접 저장 기능과 현재 임시 PDF 전송 기능을 동일하다고 표시하지 않는다.

그 아래 접을 수 있는 최근 스캔 가로 목록을 둔다. 여러 책의 저장된 페이지를 생성일 내림차순으로 모아 최근 20개를 표시하고, 탭하면 해당 책의 페이지를 연다. 보류 촬영은 저장된 페이지와 구분해 해당 책의 계속 편집 카드로 유지한다.

책 목록은 표지 썸네일, 제목, 수정일, 페이지 수를 행으로 보여 준다. 표지는 첫 페이지를 사용하고 빈 책에는 기본 아이콘을 쓴다. 수정일 정렬과 우하단 민트색 새 책 버튼을 제공한다. 검색은 상단 도구에서 접근한다. 기존 Book 모델을 유지하며 화면 문구도 `책/서재`로 통일한다. 폴더 계층을 새로 도입하지 않는다.

첨부처럼 서재 → 책 페이지 그리드를 각각 한 화면으로 표시하는 탐색을 기본으로 한다. 이전의 iPad 사이드바 상시 유지 제안은 철회한다.

### 책의 페이지 그리드

`4.페이지상세.png`를 기준으로 BookDetailView를 개편한다. 상단 뒤로/책 제목/선택/더보기를 두고, 큰 표제나 설명 없이 그리드를 배치한다. 첨부와 비슷한 iPad 전체 화면에서는 6열을 기준으로 하되 좁은 창·iPhone·큰 글자에서는 열 수를 줄인다. 이미지 전체 비율을 유지하고 간격·그림자를 최소화한다.

각 썸네일 우하단에는 현재 배열 순서에 따른 큰 페이지 번호를 표시한다. 인쇄된 책 페이지 번호와는 별개이다. 마지막에는 촬영 추가 타일을 두고, 우하단 + 버튼에서는 촬영/사진 가져오기를 선택한다. `선택`에서는 다중 선택과 선택 삭제를 제공하며 삭제 전 개수를 확인한다. 기존 단일 삭제와 순서 변경도 유지한다. PDF 내보내기와 Wi-Fi 전송은 더보기에서 접근한다.

### 단일 페이지 보기

첨부에 단일 페이지 확대 화면은 없으므로 기존 제안을 보조 설계로 유지한다. 이미지/텍스트 전환, 경계 조정, 필터, OCR, 읽어주기와 공유를 유지하고 화면 크기에 맞춘 이미지와 페이지 이동을 제공한다. 확대 중에는 이미지 이동을 우선한다.

## 구현 순서

1. **공통 스타일과 촬영 화면**: 시스템 산세리프, 검은 촬영 바, 흰색 셔터, 민트 강조색을 정의한다. CameraScannerView를 상단 바/프리뷰/모드 선택/촬영 도구/설정 시트로 분리하고 최근 결과 진입을 연결한다. 세로·가로 배치를 먼저 검토한다.
2. **경계 확인 연결**: SpreadReviewView의 표시 면적과 저장 동선을 개선한다. 촬영 검토와 저장 후 재편집의 복귀 목적지를 구분한다. 검출·분할·저장 알고리즘은 유지한다.
3. **서재·책 상세**: LibraryView와 BookDetailView의 큰 장식 문구를 줄이고 PC 전송 카드·최근 목록·정렬·새 책 버튼을 구현하고, 6열 기준 그리드·다중 선택·추가 타일을 연결한다. 보류 원본 복구와 PDF/Wi-Fi 전송 경로를 유지한다.
4. **페이지 보기**: PageDetailView를 화면 크기에 맞추고 페이지 이동/번호/하단 도구를 정리한다. 기존 이미지·텍스트 기능을 연결한다.
5. **검증과 문서화**: UI 테스트의 화면 탐색을 갱신하고 기존 검출·저장 테스트를 실행한다. 대표 화면을 캡처해 배치와 기능 동선을 확인한 후 README를 갱신한다.

주요 수정 대상은 `BookScan3/Views/CameraScannerView.swift`, `SpreadReviewView.swift`, `LibraryView.swift`, `BookDetailView.swift`, `PageDetailView.swift`와 공통 스타일이다. 필요한 상태만 ScannerViewModel/LibraryViewModel에 추가한다. 데이터 포맷 변경은 계획에 포함하지 않는다.

## 완료 기준

- 첨부 화면과 같은 크기·방향의 앱 캡처로 촬영 오버레이, 서재 최근 목록, 책 그리드를 나란히 비교한다. 비교 콘텐츠는 테스트 이미지로 사용한다.
- 서재 최근 스캔에서 해당 책/페이지로 정확히 이동하고, 정렬·목록 접기·새 책 생성이 작동한다.
- 페이지 그리드의 번호·다중 선택·삭제 확인·마지막 촬영 타일·+ 메뉴가 작동한다.

- iPad 11인치 세로/가로와 iPhone에서 셔터·1/2페이지·가져오기·최근 결과가 스크롤 없이 보인다.
- 실제 촬영 → 여섯 점 조정 → 두 페이지 저장 → 다음 촬영 흐름을 완료한다.
- 저장 후 원본 경계 재조정, 보류 후 재실행 복구, 삭제된 반대쪽 페이지 처리 회귀가 없다.
- 자동 촬영의 안정화·중복 방지와 앱 비활성화/복귀가 유지된다.
- 큰 글자와 VoiceOver에서 주요 버튼을 식별할 수 있고, 경계점은 드래그 외 미세 조정으로도 조작한다.
- PDF 내보내기, OCR, 필터, 페이지 순서 변경, Wi-Fi 전송이 기존 경로에서 작동한다.
- 원본/경계 오버레이가 회전·화면 크기 변화 후에도 일치한다. 실기기 확인은 시뮬레이터 검증과 별도로 수행한다.

촬영·경계 확인·서재·책 그리드·단일 페이지 보기까지 구현했다. 가장 자주 쓰는 촬영 화면의 변화를 먼저 평가하고, 같은 스타일을 서재와 상세 화면으로 확장한다.
